Dépôt APT de NOOS

Bureau Wayland NOOS pour Debian sid — mises à jour du bureau et de ses applications.

Ajouter le dépôt

sudo curl -fsSL -o /usr/share/keyrings/noos-archive-keyring.asc \
    https://chomiam.github.io/noos-de/noos-archive-keyring.asc
sudo tee /etc/apt/sources.list.d/noos.sources >/dev/null <<'EOF'
Types: deb
URIs: https://chomiam.github.io/noos-de
Suites: sid
Components: main
Signed-By: /usr/share/keyrings/noos-archive-keyring.asc
EOF
sudo apt update
sudo apt install noos

Le paquet noos installe ensuite lui-même ce fichier de sources et la clé : les mises à jour arrivent avec apt et dans Logiciels.
